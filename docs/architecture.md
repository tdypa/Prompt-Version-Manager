# Prompt Version Manager 信息架构（MVP）

## 1. 产品目标

Prompt Version Manager 是一个本地优先的桌面应用，用于管理“提示词项目（Prompt Set）”及其“历史版本（Versions）”，支持富附件、快速复制、导出素材包和检索。

MVP 优先目标：

- 完成项目与版本全流程 CRUD。
- 实现本地存储（SQLite + 本地 assets）。
- 提供三栏高效工作台（列表 + 历史 + 编辑）。
- 提供复制与导出能力。

## 2. 页面信息架构

应用整体采用单窗口三栏布局：

1. 顶部工具栏（全局）
   - 搜索框（搜索项目标题、标签、版本内容）
   - 新建项目按钮
   - 新建版本按钮（依赖当前选中项目）

2. 左侧栏：提示词项目列表（Prompt Sets）
   - 项目标题
   - 标签（简写展示）
   - 版本数
   - 新建/编辑/删除项目

3. 中间栏：版本列表（Version Timeline）
   - 按创建时间倒序（最新在上）
   - 每项展示：版本名称、创建时间、推荐标记、说明摘要
   - 新建/编辑/删除版本

4. 右侧栏：版本详情编辑区
   - 版本名称
   - 版本说明
   - Markdown 提示词正文（源码编辑 + 预览）
   - 附件区（图片/文档/视频）
   - 创建时间（只读）
   - 推荐版本开关

5. 底部操作区（作用于当前选中版本）
   - 复制正文
   - 复制附件路径
   - 导出版本素材包（文件夹 or zip）
   - 设为推荐版本

## 3. 功能模块划分

### 3.1 渲染进程（React UI）

- `App`：三栏布局与全局状态调度。
- `PromptSetListPane`：项目列表与项目级操作。
- `VersionListPane`：版本时间线与版本级操作。
- `VersionEditorPane`：版本详情编辑、Markdown 预览、附件维护。
- `TopBar`：全局搜索/新建入口。
- `BottomActions`：复制、导出、推荐。

### 3.2 主进程（Electron）

- `database service`
  - 初始化/迁移 SQLite 模式
  - 项目、版本、附件 CRUD
  - 搜索查询
- `asset service`
  - 附件导入（复制到本地 assets）
  - 路径规范化
  - 版本导出（目录/zip）
- `system integration`
  - 剪贴板写入
  - 文件对话框
  - IPC 边界验证

### 3.3 进程通信（Preload + IPC）

- 通过 `contextBridge` 暴露 `window.pvmApi`。
- 所有写操作经主进程校验，渲染层仅消费受控 API。

## 4. 状态与数据流

1. 启动时加载：
   - 加载项目列表
   - 默认选中第一个项目与其最新版本

2. 用户交互触发变更：
   - UI 调用 `window.pvmApi.*`
   - 主进程更新数据库与文件系统
   - 返回最新数据
   - UI 刷新对应局部状态

3. 搜索模式：
   - 顶部输入关键字
   - 主进程执行联合查询（项目标题/标签/版本内容）
   - 返回匹配的项目与版本集合

## 5. 存储架构

1. 数据库存储（SQLite）
   - 项目基础信息
   - 版本元信息与正文
   - 附件元数据（类型、路径）
   - 标签与映射关系

2. 文件存储（assets）
   - `assets/{promptSetId}/{versionId}/...`
   - 导入时复制原文件到该目录
   - 删除版本时同步清理目录

## 6. 非功能约束（MVP）

- 本地优先，不依赖远程服务。
- 界面风格简洁专业（Notion + Raycast + Figma Version History 风格）。
- 支持中英文内容输入。
- 对异常场景给出明确提示（未选中项目、导入失败、导出失败等）。
