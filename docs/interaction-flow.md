# Prompt Version Manager 交互流程（MVP）

## 1. 全局导航与默认状态

1. 应用启动后加载项目列表。
2. 若存在项目，默认选中第一个项目；版本列表展示该项目所有版本（按创建时间倒序）。
3. 若存在版本，默认选中最新版本并在右侧展开详情。

## 2. 项目（Prompt Set）管理流程

### 2.1 新建项目

1. 点击顶部「新建项目」。
2. 输入项目标题、描述、标签（逗号分隔）。
3. 保存后：
   - 左侧列表新增项目；
   - 自动选中新项目；
   - 中间版本列表为空，提示新建版本。

### 2.2 编辑项目

1. 在左侧选中项目后点击「编辑」。
2. 修改标题、描述、标签。
3. 保存后列表立即更新。

### 2.3 删除项目

1. 在左侧项目操作菜单选择「删除」。
2. 二次确认。
3. 删除后：
   - 关联版本与附件元数据删除；
   - `assets/{promptSetId}` 目录清理；
   - UI 自动切换到下一个可用项目。

## 3. 版本（Version）管理流程

### 3.1 新建版本

1. 选中一个项目。
2. 点击顶部「新建版本」。
3. 输入版本名称、说明、Markdown 正文。
4. 可选上传附件（图片/文档/视频）。
5. 保存后：
   - 中间列表按时间倒序刷新，新版本置顶；
   - 右侧显示新版本详情。

### 3.2 编辑版本

1. 中间列表点击任一版本。
2. 右侧编辑版本名称、说明、正文、推荐状态、附件。
3. 点击保存，更新时间并保持当前选中。

### 3.3 删除版本

1. 在中间列表版本项点击删除。
2. 二次确认后删除版本及关联附件文件。
3. 列表刷新并自动选中剩余最新版本（若存在）。

## 4. 版本详情与附件流程

### 4.1 Markdown 编辑与预览

1. 在右侧输入 Markdown 正文。
2. 实时预览区渲染 Markdown（基础语法）。

### 4.2 附件导入

1. 点击「添加附件」。
2. 选择本地文件（可多选）。
3. 系统按扩展名识别附件类型（image/document/video）。
4. 文件复制到 `assets/{promptSetId}/{versionId}/`。
5. 列表展示附件名、类型、路径。

### 4.3 附件删除

1. 在附件列表点击删除。
2. 删除数据库记录并尝试删除本地文件。

## 5. 搜索流程

1. 在顶部搜索框输入关键词。
2. 系统搜索项目标题、标签、版本内容（名称/说明/正文）。
3. 左侧仅展示命中项目。
4. 清空搜索词后恢复全量列表。

## 6. 复制与导出流程

### 6.1 一键复制正文

1. 选中版本后点击底部「复制正文」。
2. 系统将版本 Markdown 正文写入系统剪贴板并提示成功。

### 6.2 一键复制附件路径

1. 点击「复制附件路径」。
2. 系统将该版本全部附件绝对路径按换行拼接后写入剪贴板。

### 6.3 导出完整版本素材包

1. 点击「导出」并选择导出类型（文件夹/zip）。
2. 选择目标目录。
3. 系统导出：
   - `prompt.md`
   - `version-meta.json`
   - `attachments/*`
4. 完成后弹出目标路径提示。

## 7. 推荐版本流程

1. 选中版本后点击底部「设为推荐版本」或右侧开关。
2. 系统将同项目其他版本的 `is_recommended` 置 0，当前置 1。
3. 中间列表显示推荐标记。
